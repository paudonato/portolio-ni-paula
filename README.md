# Paula's Desktop — UGC Creator

A responsive portfolio for Paula's UGC content, built with the existing cream, blush pink, and brown branding.

## Preview locally

Open `index.html` in a browser. If Python is installed, you can instead run a local static server from this project folder:

```sh
py -m http.server 8000
```

Then visit `http://localhost:8000`. No build step or deployment is required.

## Project files

- `index.html` — portfolio sections, contact details, and Instagram Reel links
- `styles.css` — responsive layout, colors, and thumbnail styling
- `script.js` — mobile navigation toggle and keyboard behavior
- `assets/paula-portrait.jpg` — homepage portrait
- `assets/skincare.png`, `assets/desk-setup.png`, `assets/unboxing.png` — portfolio photos
